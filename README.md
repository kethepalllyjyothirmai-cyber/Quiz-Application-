# 🎯 Multiple-Choice Quiz Application

An interactive and user-friendly **Multiple-Choice Quiz Application** developed as a DAA (Design and Analysis of Algorithms) assignment. The application allows users to answer questions one at a time, validates their answers, tracks progress, calculates the score, and displays the final result.

---

## 📌 Project Overview

The Multiple-Choice Quiz Application is designed to provide a simple and interactive platform for conducting quizzes.

The application follows a structured question flow:

**Start Quiz → Display Question → Select Answer → Validate Answer → Store Response → Next Question → Calculate Score → Display Result**

It can be used for classroom quizzes, self-assessment, exam preparation, and educational activities.

---

## ✨ Features

- 📝 Multiple-choice questions
- 🔢 One question displayed at a time
- ✅ Answer selection and validation
- 📊 Real-time progress tracking
- 🎯 Automatic score calculation
- 📈 Progress bar
- 🏆 Final score display
- 🔄 Restart quiz option
- 💻 Simple and responsive user interface
- ⚡ Instant interaction and results

## 🧠 How the Application Works

1. The user starts the quiz.
2. A question with multiple options is displayed.
3. The user selects an answer.
4. The selected answer is validated against the correct answer.
5. The score is updated if the answer is correct.
6. The progress is updated.
7. The next question is displayed.
8. After all questions are completed, the final score is shown.
9. The user can restart the quiz and try again.
